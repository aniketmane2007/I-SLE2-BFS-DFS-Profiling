## 📌 Project Overview
This project profiles and compares two classic uninformed search algorithms—**Breadth-First Search (BFS)** and **Depth-First Search (DFS)**—applied to solve the **8-Puzzle problem**. The objective is to evaluate computational efficiency, execution time, and state-space expansion behavior.

---

## 📂 Repository Contents
* `Profile_Puzzle.py` — Python script implementing both algorithms with high-resolution performance timers (`time.perf_counter()`) and node expansion counters[cite: 3, 4].
* `report.md` — Formal assignment documentation and technical analysis.
